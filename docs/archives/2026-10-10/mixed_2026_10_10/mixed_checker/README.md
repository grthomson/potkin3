# Independent mixed checker

Run `python check_mixed.py` using Python 3. No third-party dependencies.

This is an independent occurrence-linear term implementation containing both
tensor and implication in the **same** type grammar and proof trees. It checks
Pair, Let, Lam, App, atomic selected primitive nodes, and atomic material-origin
holes. The type checker enforces exact single use of assumptions and globally
distinct occurrence IDs. Selected primitive rules have atomic premises and
conclusions and no hypothetical discharge in this executable fragment. There is no frozen
primitive-rule registry: these are fixed hand-constructed typed fixtures, not an
admission checker for arbitrary externally supplied primitive rules.

The implementation enumerates actual antichain material cuts before performing
any logical evaluation. Coefficients retain complete occurrence-marked material
trees and hole seams, with a commutative exterior forest product. The
coassociativity check compares full raw triples, including exact residual trees;
it does not reduce residuals or use an abstraction of the coproduct.

The symbolic evaluator supplies an eta-long comparison key for the named fixture
equations. Neutral tensor values use paired projections; function values use
closures and fresh symbolic binders, followed by alpha canonicalization. **No
global faithfulness or completeness theorem for this evaluator is claimed.** The
fixture identities are independently standard typed beta, eta, and passive
commuting conversions. Thus these checks corroborate, but do not replace, the
separate paper argument using the specified proof-identity carrier.

The finite signature checks all subsets of atomic free ports with fresh tagged
selected probes and includes whole-term purity. It uses the complete enumerated
coaction with evaluated residuals, not the previous sparse-normalizer code.
It is deliberately not a performance implementation of the paper signature.

Nine fixtures cover tensor elimination across lambda and both application
positions, tensor-valued beta arguments, mixed eta, the raw compound-input
barrier, tensor eta on a function result, and two material incompatibilities.
Eighteen additional cases install closed/open compound implementations and their
identity-wrapped versions. All cuts in the original left fixtures are checked
for interface preservation. Actual two-stage coaction equality covers 495 flag
terms across both sides and their substitutions, including four joint compound
and atomic fills with pure, impure, open, and nonprimitive payloads. Four malformed terms are
rejected (resource duplication, binder type mismatch, non-atomic primitive
output, and invalid tensor elimination).

The mixed principal reduction

`(lambda v. let (x,y)=v in r(x,y)) (d,e) --> r(d,e)`

has exactly the nonprimitive defect `r(d,e) tensor hole_r`. The test asserts the
entire coefficient difference, not just its cardinality. This illustrates why
retaining ordinary equality and retaining all composite material cuts are
different certification requirements.

`results.json` is generated by the script. All claims above are finite executable
checks; no claim is made about exhaustive testing, mechanized proofs, runtime
speedup, hypothetical primitive discharge, or native repository integration.

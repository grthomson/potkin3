# POTKIN3 documentation index — 12 October 2026

This is the navigation and relocation record for the 12 October documentation
cleanup. No historical document or bundle was merged, discarded or overwritten.
All 128 initially relocated files retain their original contents, including
duplicate snapshots, prototype sources, validation logs and result files. The
subsequent context/revival research relocation preserved 63 additional files
as one intact bundle, with no content changes.

The organisation separates current native records from earlier research claims.
It does not upgrade any result's mathematical status. Relocation is a static
preservation operation, not Lean verification. Each dated report records its
own execution and status separately; no archived prototype was run as part of
the document organisation.

## Folder conventions

| Location | Purpose |
| --- | --- |
| `docs/reference/` | Foundational architecture and provenance/theorem ledgers; original dates are not supplied where the source is undated. |
| `docs/reports/2026-10-12/` | Current native reports catalogued on 12 October; their internal dates and continuation history are preserved. |
| `docs/checkpoints/YYYY-MM-DD/` | Standalone research checkpoints grouped by the date stated in their contents or filename. |
| `docs/archives/YYYY-MM-DD/` | Complete historical packages grouped by their recorded package date, without changing internal names or contents. |
| Repository root | README, repository instructions, semantic policy and build entry points. |
| `Potkin/` | Native Lean source, not recovered research exports. |

The index date is the organisation date, not a retroactive claim about when every
document was written. Undated notes inside a dated bundle inherit its location
for navigation only; their own authorship dates remain unspecified.

1. The theorem we should prove

FORMULA GATE. The generic mechanized result quantifies over an arbitrary relation
Imp : Formula -> Formula -> Formula -> Prop. Source adequacy cannot inherit that
arbitrariness. For an independently chosen source formula grammar and encoding e,
prove both directions
  Imp(e A)(e B)(e C) iff C = (A -> B)
on the encoded fragment (or an equivalent native constructor characterization).
If native formulas do not contain implication directly, exhibit its encoding and
prove injectivity/distinctness and this characterization. A schematic Imp predicate
with no adequacy theorem only proves a conditional result for a decorated registry.

SEQUENT GATE. Encode each source sequent as the appropriate singleton native
hypersequent, retaining context multisets and their local occurrence information.
For weakening/contraction, preserve the actual native incidence witness identifying
the added/contracted formula occurrences. Equal displayed multisets alone do not
prove equality of an admitted rule instance. All schema descriptors below include
the native incidence field; the registry construction is conditional on producing
that witness from each independently specified source rule application.

Fix the represented propositional fragment: identity, internal weakening and
contraction, implication-right, and the two tops and bottom of Sys(com). Fix
arbitrary finite formula multisets Phi, Psi, Gamma, formulas A,B, and system
identifier u. Set S = Gamma,A => B and T = Gamma => A -> B. Let R:S->T be
implication-right and let B(u,Phi,Psi;X) have ordered premises X,X and conclusion
X. Define two native open shells

  C  = R(B(u,Phi,Psi;S)(Box_S,Box_S)),
  C' = B(u,Phi,Psi;T)(R(Box_S),R(Box_S)).

SCHEMA-GENERAL OPEN PERMUTATION. For arbitrary typed native P,Q:S and arbitrary
typed puncture context E expecting T,

  Legal(E[C[P,Q]]) iff Legal(E[C'[P,Q]]).

The owner UID u is unchanged. All top references in P,Q,E are unchanged.
There is no freshness premise: duplicate declarations, inaccessible references,
and malformed fillers must remain equivalent failures. Local exactness and
registry admission are separate from this arbitrary-input legality equivalence.

ADMITTED COROLLARY. For any immutable registry Rg that contains exact validated
instances for the two bottoms and implication-right, and for donors/context
admitted in that same Rg, both constructions are admitted and the displayed
equivalence holds for their realized native trees. Each shell rule is checked
against the independently specified source schema; membership in an arbitrary
registry alone is not a proof of logical validity.

FINITE COMMON REGISTRY EXISTENCE. Given a finite schema-valid source derivation,
its finite transformed derivation, and finite schema-valid donors/exterior, one
can construct a single finite immutable registry admitting all of them, without
changing any system UID or rule-discharge reference. If an existing registry is
to be retained, use a conflict-free conservative extension of its finite instance
table and an explicit checked-derivation lifting theorem.

These are the correct quantifiers. A single fixed finite registry cannot contain
all arbitrary formula instances. Do not silently substitute the ten-instance
fixture for either quantified statement.

3. Independent schema validation and finite admission

A rule descriptor records the schema tag, concrete formula/multiset parameters,
ordered premise boundaries, conclusion boundary, and the exact incidence data
required by the native registry. Sys(com) descriptors additionally record system
UID, role where applicable, and shared parameters. Exact logical validity is the
independently defined schema relation. It is NOT defined to mean that a registry
lookup succeeds, and it is NOT defined by discharge-summary success.

Take the finite list of descriptor occurrences used by the derivations. Allocate
fresh RULE-INSTANCE identifiers for these descriptors (deduplication of literally
equal descriptors is optional and unnecessary for existence). Store each with its
schema-validation witness. For a fixed existing registry retain all its bindings
literally and allocate new keys outside its domain. Structural induction on each
derivation constructs its quotation/admission witness from the lookup witnesses
and the admitted ordered children. Typed holes use the existing open-interface
mechanism; only complete derivations may use a constructor requiring completeness.

Rule-instance keys are lookup names. System UIDs express discharge identity.
Allocating fresh rule-instance keys never freshens or changes a system UID.
The source and target bottom descriptors usually need distinct keys because their
common boundary changes from S to T; they nevertheless carry the SAME UID u.
The two target R occurrences can use the SAME exact rule-instance key because
rule-instance keys need not be unique occurrence IDs. Physical occurrences remain
distinct through native addresses.

If the native instance-key type does not supply arbitrarily many fresh keys, the
extension theorem must assume the needed capacity or use the project's actual
schema-backed presentation mechanism. Do not claim an unverified allocation API.

4. Registry extension theorem and its exact limits

Define Rg <= Rg' to mean every old admitted exact instance lookup is preserved
with identical conclusion, ordered premises, payload, and incidence; the logical
signature/formula interpretation is unchanged. Under that relation:

  (a) every Rg-admitted native quotation can be lifted to Rg';
  (b) realization of the lifted quotation equals the old realization;
  (c) all independent Legal facts and direct summaries are unchanged.

Proof of (a,b): induction on the quotation, replacing each membership witness by
the extension witness and keeping constructors/children. Proof of (c): substitution
along (b), since those relations inspect the actual tree, not registry membership.

This is conservative ADMISSION, not a theorem that adding rules is a conservative
logical extension. New derivations may be admitted in Rg'. No base-change/Hopf-map
claim follows. An inclusion that changes an old rule's descriptor is not adequate.
If realization embeds presentation-specific labels, prove exact forgetful equality
or the already available representation transport; do not assume definitional
equality across snapshots.

5. Repeated UIDs and contextual normalization

UID42 in the fixture is harmless for its one transformed owner. It is not a
universal owner name to reuse in a larger derivation. For multiple disjoint
systems, choose u1,...,un pairwise distinct, or retain the already unique names
from a legal input derivation. A local transformation retains its selected u.
The generic failure-reflecting theorem needs no added freshness assumption; if
the whole source is legal, its owner uniqueness already implies the necessary
noncollision with other bottoms. Source and target each contain exactly one copy
of this bottom, not both alternatives simultaneously.

Sequentially transform any finite chosen sequence of eligible unary/bottom redexes.
At every stage use the exterior-context theorem. Induction gives endpoint legality
equivalence and preservation of the owner inventory. Compile a common registry
from all finitely many stage descriptors, or extend incrementally with the lifting
lemma. This is closure under finite transformation sequences, NOT termination or
confluence, and NOT copying bottom owners. D1 cut elimination remains open.

the existing summary cut-evaluation and certificate-gluing theorems apply. Their
